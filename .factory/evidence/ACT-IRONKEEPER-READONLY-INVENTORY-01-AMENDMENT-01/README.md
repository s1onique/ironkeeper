# ACT-IRONKEEPER-READONLY-INVENTORY-01-AMENDMENT-01 — evidence

This directory is the evidence bundle of the M1 amendment. The amendment
repairs concrete safety, attribution and observation-correctness defects
of the M1 read-only inventory implementation; it does not extend the
milestone.

| File | Contents |
|---|---|
| `entry-identity.md` | The entry authority and the branch |
| `red-reproductions.md` | The defects, reproduced against the production path |
| `green-witnesses.md` | The witnesses that establish the repairs |
| `non-vacuity.md` | The non-vacuity checks and their observed results |
| `privacy-history.md` | The public-history privacy status (W9) |
| `coverage-reconciliation.md` | The reconciled coverage and receipt identities (W10) |
| `live-requalification.md` | The operator requalification procedure |
| `native-ci.md` | The native Linux execution results |
| `remaining-limitations.md` | What is deliberately not implemented |
| `exit-receipt.yaml` | The exit receipt |

No real device identity, serial number, WWN or raw capture from the live
host is committed here. The privacy section names the *locations* of the
identifiers that the predecessor committed; it never reproduces them.
